# Videos

Drop your video files here.

Expected files (referenced by `projects.html`):

- `ppo-agent.mp4` — the PPO movement agent demo for the BrainHack TIL-AI
  Competitions cell. The video appears inside a "Watch the PPO agent"
  toggle on the Projects / Competitions page.

You can also drop a `.webm` next to the mp4 (e.g. `ppo-agent.webm`) and the
player will pick whichever the browser prefers — see the `<video>` element
in `projects.html`.

If the file is missing, the toggle still renders but the video player will
show its native "couldn't load" UI.
